# 온담 패키지 홈페이지

패키지 디자인·제작 전문기업 (주)온담의 회사 소개 사이트입니다.

- 사이트 주소: https://modoit-ai.github.io/ondam-package/
- 구성: `index.html` 한 장 + `images/` + `config.js`
- 문의 폼은 구글 Apps Script(`apps-script/Code.gs`)를 거쳐 구글 드라이브의 **온담 문의 접수** 시트와 **첨부파일** 폴더에 저장됩니다.

## 문의 폼 연결 방법 (처음 한 번)

1. 구글 시트 **온담 문의 접수**를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 구글 계정 권한(시트·드라이브·메일)을 허용합니다.
6. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
7. `config.js`의 `endpoint` 따옴표 안에 붙여 넣고, `index.html`의 `config.js?v=숫자`를 하나 올린 뒤 GitHub에 올립니다(브라우저 캐시 갱신).

연결 확인: 웹 앱 URL을 브라우저로 열었을 때 `{"ok":true,"service":"온담 문의 접수"}`가 보이면 정상입니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로).
